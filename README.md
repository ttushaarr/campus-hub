# CampusHub

My first repository: a student portal for viewing student information, courses, and campus announcements.

## Run locally

Open `index.html` in a web browser. CampusHub is a static project and does not need a package install or server.

## Project structure

- `index.html` — portal entry point
- `src/components/` — reusable page sections
- `src/pages/` — page content
- `assets/` — styles and browser scripts
- `docs/` — project notes

## Git workflow

The dashboard work is on the `feature/dashboard` branch. Review and merge it through a pull request.
